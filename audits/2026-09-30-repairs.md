# Repair verification — September 30, 2026

## Completed fixes

- AI rename conflicts return HTTP 409 with a useful message.
- Task deadlines and plan-day dates synchronize in both directions. Plan start dates and material previews are updated too.
- PATCH requests validate required fields, title lengths, and empty activities.
- Standalone and offline plan generation honor explicit start dates.
- Deleting a conversation no longer blocks continuation with the available context.
- Combined revisions can update content and distribute time evenly. Later revisions retain the new content.
- Planned sessions create scheduled tasks. Completed sessions are recorded separately and cannot have a future completion date.
- Material generation creates a preview. Subjects/topics, tasks, and materials are saved only after approval; repeating the same approval is rejected.
- Closing the assistant aborts the browser request and prevents late speech or memory updates.
- Loading failures are shown to the user. Stale loading responses are ignored after logout or a newer refresh.
- Bulk selection respects the 1000-item limit.
- Plan-day editing supports five-minute sessions.
- Manual notes and offline plans remain available after the AI quota is exhausted.
- Weekly statistics exclude future dates.

## Verification at the time of repair

- **83 backend tests passed** on isolated PostgreSQL, including the eight original audit cases.
- TypeScript compilation and the production Vite build passed.
- Chromium smoke checks passed with controlled API responses: preview, regeneration without duplicates, explicit approval, deleting 1000 of 1001 history entries, closing a pending request, opening the assistant at a 390-pixel viewport, and no JavaScript runtime errors.
- Cross-account tests denied reading, shifting, duplicating, regenerating, and deleting another user's plans and exporting their notes.
- Invalid tokens were rejected. Script tags in note exports were escaped.
- A live AI check generated and approved a three-day plan starting October 1, 2026, and scheduled a future session without increasing today's study total. All database writes from that diagnostic were rolled back.
- The deployed readiness endpoint confirmed database connectivity, current migrations, and configured AI.

Maintained tests: `tests/test_api.py` and `tests/test_user_journeys.py`. Browser scenarios: `audits/browser-smoke.mjs`.

## Limitations

These checks do not guarantee the absence of all defects or vulnerabilities. Physical-phone microphones, Safari, and all possible user utterances were not exhaustively tested. Aborting a browser request does not guarantee cancellation of a provider request already being processed; late results do not trigger a browser-side material save.

Test counts are historical. Run the current suite for the latest result.
